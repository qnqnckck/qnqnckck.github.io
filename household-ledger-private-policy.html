가계부 개인정보처리방침

시행일 및 최종 수정일: 2026년 8월 9일 · 앱 ID: com.labhub.householdledger

가계부(머니로그)는 사용자의 생활 장부를 기기 중심으로 관리하는 로컬 우선 앱입니다. 개발자는 장부 내용을 수신하는 회원 계정이나 자체 백엔드 서버를 운영하지 않습니다. 다만 Google Mobile Ads SDK는 아래와 같이 광고 제공에 필요한 일부 정보를 처리할 수 있습니다.

처리하는 정보

  • 사용자가 직접 입력한 거래 금액, 날짜, 상점 또는 상대방, 카테고리, 계정, 메모, 태그, 첨부 정보
  • 검토 상태, 중복 의심 처리, 반복 지출 변화 처리, 마감 상태
  • 앱 설정, 언어, 테마, 위젯 개인정보 표시 설정
  • 사용자가 카메라 또는 사진 선택기로 직접 고른 영수증 이미지

정보 사용 목적

  • 가계부 기록, 수정, 분류, 검토 기능 제공
  • 중복 기록, 카테고리 누락, 반복 지출 변화 등 사용자 확인 항목 표시
  • 계획, 마감, 위젯, 언어와 테마 설정 유지
  • 사용자가 선택한 입력 보조 기능 제공

저장 및 전송

핵심 데이터는 사용자의 기기 내 앱 저장 공간에 저장됩니다. 가계부는 거래 기록을 개발자 서버로 전송하지 않습니다. 사용자는 운영체제의 공유 화면이나 파일 선택기를 통해 JSON 백업과 월별 CSV를 직접 내보내거나 복원할 수 있습니다. 앱 밖으로 내보낸 파일은 사용자가 선택한 저장 위치와 대상 서비스의 정책에 따릅니다.

권한

카메라는 사용자가 영수증 촬영을 선택할 때만 사용합니다. 사진은 운영체제 선택기를 통해 사용자가 고른 항목에만 접근합니다. 인터넷 및 네트워크 상태 권한은 광고 제공과 사용자가 명시적으로 활성화하는 로컬 데스크톱 연결 기능에 사용됩니다.

광고

무료 버전은 비핵심 화면에 Google Mobile Ads(AdMob) 배너 광고를 표시할 수 있습니다. Google Mobile Ads SDK는 광고, 분석, 부정행위 방지, 보안 및 규정 준수를 위해 광고 ID를 포함한 기기 또는 기타 식별자, IP 주소로 추정되는 대략적 위치, 앱 상호작용 및 진단 정보를 수집하거나 공유할 수 있습니다. 거래 금액, 상점명, 계정명, 메모, 태그와 영수증 이미지는 앱이 광고 요청 데이터로 전달하지 않습니다.

동의 및 제3자 처리

동의가 필요한 지역에서는 Google User Messaging Platform을 통해 광고 동의를 요청하며, 필요한 경우 앱 설정에서 광고 개인정보 선택을 다시 열 수 있습니다. 광고 요청이 허용되지 않더라도 핵심 장부 기능은 사용할 수 있습니다. 자세한 내용은 Google 개인정보처리방침과 Google 광고 기술 안내를 확인해 주세요.

보관 및 삭제

기록은 사용자가 삭제할 때까지 기기에 보관됩니다. 개별 기록은 앱에서 삭제할 수 있고, 앱 데이터 삭제 또는 앱 제거로 앱 전용 데이터를 제거할 수 있습니다. 운영체제 백업이나 앱 밖으로 내보낸 JSON·CSV 파일은 별도로 남을 수 있으므로 해당 위치에서 직접 삭제해야 합니다. 개발자 서버 계정이 없으므로 별도의 계정 삭제 절차는 없습니다.

아동의 개인정보

가계부는 일반 성인 및 가정 사용자를 위한 도구이며 아동을 대상으로 설계되지 않았습니다. 개발자는 아동의 개인정보를 고의로 수집하지 않습니다.
