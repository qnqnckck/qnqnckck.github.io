Bias Binder Support

카드 사진은 어디에 저장되나요? / Where are photos stored? / 写真の保存先は？

사진과 컬렉션 정보는 앱의 기기 내 저장소에 보관됩니다. / Photos and collection data stay in the app's on-device storage. / 写真とコレクション情報は端末内に保存されます。

백업은 어떻게 하나요? / How do I back up? / バックアップ方法は？

설정에서 JSON 백업을 내보내고 안전한 위치에 보관하세요. 복원은 기존 목록을 백업 내용으로 교체합니다. / Export a JSON backup from Settings and keep it somewhere safe. Restore replaces the current list. / 設定からJSONを書き出して安全な場所に保管してください。復元すると現在の一覧が置き換わります。

Pro 구매가 보이지 않아요 / Pro is unavailable / Proが表示されない

스토어 연결과 판매 지역을 확인한 뒤 구매 복원을 실행하세요. 기본 컬렉션은 계속 사용할 수 있습니다. / Check store access and region, then use Restore purchase. The basic collection remains available. / ストア接続と販売地域を確認し、購入を復元してください。基本機能は引き続き利用できます。
