# Paper Dock release-site completion

## Idea summary

Bring the existing Paper Dock public pages into exact alignment with the six-tool, local-first, one-time-Pro release candidate and use them as the authoritative Google Play/App Store marketing, support, and privacy URLs.

## MVP scope

- Core problem: store reviewers and users need accurate public information before installing or purchasing.
- Must-have flows: understand all six PDF tools, open support, read privacy and billing behavior, return to the LABHUB directory.
- Out of scope: accounts, web PDF processing, document upload, analytics, and remote support chat.
- Success criteria: responsive pages, working internal links, current icon/package ID, accurate no-ads/no-analytics claims, six-tool and Pro descriptions matching the app.

## Feature specification

- Landing: document-dock metaphor, six real tools, Free/Pro value exchange, local-processing promise.
- Support: actionable recovery for encrypted/corrupt PDFs, cancellation, storage, purchase restore, and safe contact guidance.
- Privacy: on-device document handling, app-private retention/deletion, optional share disclosure, and store billing disclosure.
- Directory: current icon, description, and landing/support/privacy links.
