온라인 변환기에 민감한 문서를 올리지 마세요. Paper Dock은 PDF 합치기와 압축을 휴대폰 안에서 처리하고, 결과를 안전한 내보내기 트레이에 보관합니다.

기능 보기도움 받기
PDF 합치기두 개 이상의 PDF를 선택한 순서대로 하나의 문서로 만듭니다.
PDF 압축이미지 품질을 직접 선택하고 문서 용량을 기기 안에서 줄입니다.
내보내기 트레이완료 파일은 앱 전용 저장소에 남고, 사용자가 공유할 때만 외부로 나갑니다.
NO ACCOUNT / NO CLOUD / NO ANALYTICS

핵심 기능은 계정, 서버, 분석 SDK 없이 오프라인에서 작동합니다. 원본 PDF는 수정하거나 삭제하지 않습니다.
