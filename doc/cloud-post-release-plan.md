# Cloud Post public release pages

## Idea summary
Create original sky-post landing/support/privacy pages in google-privacy/cloud-post, using Household Ledger navigation/completeness as structural reference.

## MVP scope
Three offline static pages with KO/EN/JA/ES copy, real icon/gameplay art, truthful pre-release status and router links. No fabricated download links or tracking. Success: responsive browser review and live HTTPS verification.

## Feature specification
Language links keep equivalent content; support offers troubleshooting/contact; privacy explains local saves, optional ads and Google SDK data; router exposes three pages. Missing live links block publication completion.

## Wireframe
Header [LABHUB / Intro / Support / Privacy] → language row → courier hero / gameplay evidence → modes / local data / optional ads → footer/contact. Support and privacy use same paper document system.

Direction: sky postal sheet and dispatch coral, existing original icon and route screenshot; no new artwork. Existing app references remain unchanged. Cross-folder impact: public site only adds this app pages/router; app source is not imported into runtime.
