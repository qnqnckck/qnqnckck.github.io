# LABHUB public site rules

- Keep changes scoped to this static GitHub Pages site.
- Preserve existing hand-authored HTML and unrelated working-tree edits.
- Store project-specific plans and review notes under `doc/`.
- Keep pages usable without a backend or build step.
- Store app-specific public pages under `google-privacy/{app-slug}/`.
- Never add secrets, analytics, or runtime service dependencies.
- After UI changes, verify desktop and mobile layouts in a browser and check for console errors.
- Verify internal links and public HTTPS URLs after deployment.
